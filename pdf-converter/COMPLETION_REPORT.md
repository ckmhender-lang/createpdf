## 🚀 HOW TO RUN THE APP

### Option 1: Quick Start (3 Commands)

```bash
cd pdf-converter
npm install
npm start
```

Then scan the QR code with Expo Go!

### Option 2: Automated Setup

```bash
cd pdf-converter
./setup.sh
```

### Platform-Specific

```bash
# iOS Simulator (macOS only)
npm run ios

# Android Emulator
npm run android

# Web Browser
npm run web
```
