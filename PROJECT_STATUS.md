## 🚀 QUICK START

### Get the app running in 3 steps:

```bash
# 1. Navigate to the project
cd pdf-converter

# 2. Install dependencies
npm install

# 3. Start the app
npm start
```

**Then**: Scan the QR code with Expo Go on your phone!

## 🎨 CUSTOMIZATION

The app is designed to be easily customized:

### Change Colors
Edit `pdf-converter/src/constants/colors.ts`:
```typescript
export const Colors = {
  primary: '#6366F1',    // ← Change this
  secondary: '#EC4899',  // ← And this
  // ...
};
```

### Modify Screens
All screens are in `pdf-converter/src/screens/`:
- `HomeScreen.tsx`
- `ImageToPDFScreen.tsx`
- `MergePDFScreen.tsx`
- `DocumentsScreen.tsx`
- `PDFViewerScreen.tsx`
